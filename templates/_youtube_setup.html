How to get client_secret.json (5 minutes, one-time)
  1. Open console.cloud.google.com and sign in with the Google account that owns your YouTube channel.
  2. Top bar → Select a project → NEW PROJECT. Name it "Shadow Edge Ops" (any name works). Wait ~30 sec for it to provision, then select it.
  3. Sidebar → APIs & Services → Library. Search "YouTube Data API v3". Click it. Click ENABLE.
  4. Sidebar → APIs & Services → OAuth consent screen. Pick External. Fill in App name (e.g. "Shadow Edge Ops"), your email, and a support email. Save and continue through the scopes/test-users screens (no scopes needed here, no test users needed if your account is the channel owner). On the final screen click Back to Dashboard.
  5. Sidebar → APIs & Services → Credentials. Click + CREATE CREDENTIALS → OAuth client ID.
  6. Application type: Web application. Name: any. Under Authorized redirect URIs, add exactly:
    {{ redirect_uri }}
  7. Click CREATE. A "OAuth client created" dialog appears with a download icon — click DOWNLOAD JSON.
  8. Save (or move) that file to:
    {{ client_secret_path }}
    Rename it to client_secret.json.
  9. Refresh this page. Step 2 will unlock.
